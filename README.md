# Expense Tracker

A simple command-line expense tracker written in Python.

## Features
- Add an expense (amount, category, description)
- View all expenses
- View the total cost

## How to run
1. Install Python 3
2. Run:
```
python main.py
```

## Notes
Expenses are stored in memory only, so they are lost when the program closes.
(File saving is planned as the next step.)
